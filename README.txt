Steps to Building and Flashing Fingerprint Door Lock Program

Open Microchip Studio
Go to File-> Open -> Project/Solution
Open the Unzipped Program Files

Connect your ATmega328p/pb to your computer using the power/programming cable
Build the program by going to Build-> Build Solution
Once the program has successfully been built, ensure no errors were found

To program the board:
Click on Tools-> Device Programming or use the shortcut of Ctrl+Shift+P
Ensure the proper tool, board and interface are selected and click "Apply"
Then, press read on the device signature
Once your board signature has been verified, on the side bar select Memories
On the memory tab under Flash click the program button
On the bottom of the Device Programmer you will see a progress bar and the board will be programmed once that is finished, the board is programmed
